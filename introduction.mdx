Cryptoducks is a hands-on demo application built with React 18 and Vite that walks you through the core patterns of frontend authentication and authorization. It is used as a teaching resource in the TripleTen web development bootcamp (Spanish edition) and covers everything from user registration and login to protecting routes and persisting sessions across page reloads.

## What you will learn

Working through this project teaches you:

- How to register and authenticate users against a REST API using `fetch`
- How to store a JWT in `localStorage` and retrieve it on subsequent visits
- How to build a reusable `ProtectedRoute` component with React Router v6
- How to redirect unauthenticated users to `/login` and authenticated users away from login/register pages
- How to fetch user data from a protected endpoint using a `Bearer` token

## Project structure

The application is intentionally small so every part is easy to trace:

```
src/
├── components/
│   ├── App.jsx            # Root component — state, routing, handlers
│   ├── Login.jsx          # Login form
│   ├── Register.jsx       # Registration form
│   ├── ProtectedRoute.jsx # Route guard component
│   ├── Ducks.jsx          # Protected page — duck list
│   ├── MyProfile.jsx      # Protected page — user profile
│   ├── NavBar.jsx         # Navigation bar with sign-out
│   ├── DuckList.jsx       # Renders duck cards
│   ├── DuckCard.jsx       # Single duck card
│   └── Logo.jsx           # Logo component
└── utils/
    ├── auth.jsx           # register() and authorize() API calls
    ├── api.jsx            # getUserInfo() API call
    ├── token.jsx          # localStorage token helpers
    └── data.js            # Static duck data
```

## Routes

| Path | Access | Component |
|------|--------|-----------|
| `/login` | Anonymous only | `Login` |
| `/register` | Anonymous only | `Register` |
| `/ducks` | Authenticated only | `Ducks` |
| `/my-profile` | Authenticated only | `MyProfile` |
| `*` | Redirects | `/ducks` or `/login` |
