---
title: "Quickstart — clone and run Cryptoducks in minutes"
description: "Clone the Cryptoducks repo, install dependencies, and run the Vite dev server on port 3002 to explore JWT authentication in under 5 minutes."
---

Cryptoducks is a React 18 + Vite demo application that teaches JWT-based authentication and protected routing, used in the TripleTen Spanish-language web development bootcamp. By the end of this guide you will have the app running locally, a registered account, and hands-on access to every route — from the login page to the protected Ducks view.

<Steps>

  <Step title="Clone the repository">
    ```bash
    git clone https://github.com/ferni2309/frontend-authorization-demo-es.git && cd frontend-authorization-demo-es
    ```
  </Step>

  <Step title="Install dependencies">
    <CodeGroup>

    ```bash npm
    npm install
    ```

    ```bash yarn
    yarn install
    ```

    ```bash pnpm
    pnpm install
    ```

    </CodeGroup>
  </Step>

  <Step title="Start the development server">
    ```bash
    npm run dev
    ```

    The `dev` script runs `vite --open`, which opens your browser automatically. The app is served at **http://localhost:3002**.
  </Step>

  <Step title="Explore the application">
    The browser lands on `/login`. From there you can:

    1. Click the registration link and create a new account at `/register`.
    2. Log in with your credentials — the app stores your JWT in `localStorage` and redirects you to `/ducks`.
    3. Visit `/my-profile` to see your account details while authenticated.
    4. Sign out to confirm that protected routes redirect back to `/login`.
  </Step>

</Steps>

<Note>
  Cryptoducks connects to the hosted API at `https://api.nomoreparties.co`. No local backend setup is required — clone the frontend and start immediately.
</Note>

## Available scripts

These scripts are defined in `package.json` and run with your chosen package manager.

| Script | Command | Description |
|--------|---------|-------------|
| `dev` | `vite --open` | Starts the Vite dev server and opens the browser at http://localhost:3002 |
| `build` | `vite build` | Bundles the app for production output |
| `lint` | `eslint . --ext js,jsx --report-unused-disable-directives --max-warnings 0` | Runs ESLint across all JS and JSX files |
| `preview` | `vite preview` | Serves the production build locally for review |
